# Библиотека компонентов

Слайды пишутся вручную в HTML — это даёт точный контроль над композицией.
Готовые блоки ниже покрывают почти любой дек; собирать новые из голого CSS
почти никогда не нужно.

## Правила разметки

**Один слайд — один `<section class="slide">`.** Скрипт сам считает слайды и
собирает навигацию, поэтому вставить слайд в середину можно без правок в
остальных.

**Содержимое живёт в `<div class="wrap">`.** Он держит максимальную ширину
колонки и центрирует её.

**Порядок появления — `data-r style="--i:N"`,** где N считается от 0 в порядке
чтения. Элементы всплывают по очереди, когда слайд открывается.

**Ритм задаётся соседством блоков, а не отступами в разметке.** `.grid + .note`,
`.steps + .takeaway` и подобные пары уже разведены в CSS. Ставить `margin` в
атрибуте `style` не нужно — именно так деки и разъезжаются.

**Никаких цветов и размеров в разметке.** Всё уже в токенах бренда: цвет
акцента один, кегли фиксированы. Ручной `color:#...` ломает переносимость кита.

## Каркас слайда

```html
<section class="slide">
  <div class="wrap">
    <div class="eyebrow" data-r style="--i:0">
      <span class="ix">01</span><span>Раздел</span><span class="ln"></span>
    </div>
    <h2 data-r style="--i:1">Заголовок с <span class="ac">акцентом</span></h2>
    ...
  </div>
</section>
```

Ритм всегда один: надзаголовок → заголовок → содержание. Он делает дек
предсказуемым для зрителя и экономит ему внимание.

## Обложка

```html
<section class="slide cover">
  <div class="brandmark">
    <img src="assets/media/logo.png" alt="">
    <span class="strap">Короткая строка позиционирования</span>
  </div>
  <div class="wrap">
    <h1 data-r style="--i:0">Заголовок <span class="ac">дека</span></h1>
    <p class="lead" data-r style="--i:1">Одно предложение о том, что внутри.</p>
    <div class="meta" data-r style="--i:2"><span>Город · 2026</span><span>site.kz</span></div>
  </div>
</section>
```

## Карточки

```html
<div class="grid c3">
  <div class="card" data-r style="--i:2">
    <i data-icon="shield"></i>
    <h3>Заголовок</h3>
    <p>Пояснение в одно-два предложения.</p>
  </div>
</div>
```

`c2` / `c3` / `c4` — число колонок. `card flat` — без плашки, с линией акцента
сверху: спокойнее выглядит, когда карточек много.

Карточки внутри слайда держите одинаковыми: если у одной есть иконка или
подпись, они есть у всех. Разнобой читается как небрежность быстрее, чем любая
другая ошибка вёрстки.

Иконки: `shield chart bolt gear users clock check target layers lock globe
server doc arrow spark money warn grid`. Новые добавляются в словарь `ICONS`
в `scripts/build_deck.py`.

## Цифры

```html
<div class="grid c3">
  <div class="stat" data-r style="--i:2">
    <div class="num" data-count="38" data-suffix="%">38%</div>
    <div class="lab">Что означает эта цифра</div>
  </div>
</div>
```

Число досчитывается от нуля при показе слайда. `data-prefix`, `data-suffix`,
`data-decimals` управляют форматом. В PDF цифра фиксируется на конечном
значении.

Больше четырёх цифр на слайде не ставьте: они перестают читаться как
достижения и превращаются в таблицу.

## Список строк

```html
<div class="rows">
  <div class="row"><span class="n">01</span><span>Этап</span><span class="rt">2 недели</span></div>
</div>
```

Для повестки, этапов, состава работ. Третья колонка опциональна.

## Шаги

```html
<div class="steps">
  <div class="step on"><div class="sn">Неделя 1–2</div><h3>Аудит</h3><p>Что делаем.</p></div>
  <div class="step"><div class="sn">Неделя 3–4</div><h3>Контур</h3><p>Что делаем.</p></div>
</div>
```

`step on` подсвечивает текущий или первый шаг.

## Слайд с изображением

```html
<section class="slide hasmedia">
  <div class="media"><img src="assets/media/photo.jpg" alt=""></div>
  <div class="wrap">…</div>
</section>
```

Изображение занимает правую часть, текст — левую, между ними мягкий градиент к
фону. Берите горизонтальные снимки: вертикальные обрежутся по центру.

## Мелкие блоки

```html
<div class="pills"><span class="pill on">Главное</span><span class="pill">Ещё</span></div>

<div class="note"><span class="mk"></span><div><b>Важно:</b> текст в рамке.</div></div>

<div class="takeaway"><b>Вывод:</b> одна мысль, которую унесут со слайда.</div>

<blockquote class="quote">Цитата в одну-две строки.</blockquote>
<div class="who">Имя, должность</div>

<div class="logos"><img src="assets/media/partner.svg" alt=""></div>
```

`takeaway` ставьте не чаще чем на каждом третьем слайде: если вывод есть
везде, его нет нигде.

## Что делать, если не помещается

Скрипт сам ужимает содержимое слайда, которое не влезло по высоте, и пишет об
этом в консоль браузера (`data-fit` на секции). Это страховка от обрезанного
текста в зале, а не разрешение класть больше.

Если слайд ужат сильнее чем до 85%, разбейте его надвое: мелкий текст на
проекторе не читается с последнего ряда, каким бы аккуратным ни был макет.
