# Skills

Четыре AI-скилла для бизнес-задач: подготовка коммерческих предложений, анализ конкурентов, обработка очереди клиентских обращений и презентации в фирменном стиле компании.

Скиллы написаны для [Claude Cowork](https://claude.com/product/cowork) / Claude Code и работают в любой среде, где Claude может читать `SKILL.md` и запускать Python.

## Что внутри

| Скилл | Что делает | Что отдаёт |
|---|---|---|
| [`kp-generator`](kp-generator/) | Собирает персонализированное коммерческое предложение: профиль компании + бриф по сделке + веб-ресёрч по клиенту | PDF и DOCX |
| [`competitor-radar`](competitor-radar/) | Разбирает рынок и следит за изменениями: игроки, карта позиционирования, сравнение, выводы | Интерактивный HTML-дашборд |
| [`support-queue`](support-queue/) | Обрабатывает очередь обращений: отвечает по базе знаний, сложное передаёт менеджеру со справкой | Страница проверки черновиков + CSV |
| [`brand-deck`](brand-deck/) | Разбирает фирменный стиль по презентациям компании и собирает новые деки в нём | Самодостаточный HTML + 16:9 PDF |

## Общий принцип

Все три построены вокруг одного правила: **скилл не выдумывает факты**.

- Каждое утверждение опирается на источник — профиль компании, базу знаний, найденную страницу
- Неизвестное помечается явно (`[[УТОЧНИТЬ: …]]`, «нет данных», эскалация), а не заполняется правдоподобным
- У данных проставлена достоверность: подтверждено / косвенно / оценка

Это делает результат пригодным для отправки клиенту без переписывания и, что важнее, честным в цифрах: `support-queue` на демо-наборе закрывает 60% обращений без человека, а не 90%, как обещают в презентациях.

`brand-deck` следует тому же правилу с другой стороны: дизайн не сочиняется, а вычитывается из PPTX клиента — палитра, гарнитуры, шкала кеглей и поля берутся из файлов, а не подбираются на глаз.

## Установка

**Cowork / Claude.ai** — скачайте нужный `.skill` из [`dist/`](dist/) и загрузите в чат: на карточке файла появится кнопка «Save skill».

**Claude Code** — скопируйте папку скилла в `~/.claude/skills/`:

```bash
git clone https://github.com/dynyaa/skills.git
cp -r skills/kp-generator ~/.claude/skills/
```

После этого скилл подхватывается автоматически, когда задача ему подходит.

## Требования

Python 3.9+. Для сборки PDF нужен Chrome или Chromium (headless), для DOCX — `python-docx`, для чтения XLSX — `openpyxl`, для презентаций — `python-pptx`, `fonttools`, `brotli`, `playwright`, `img2pdf`:

```bash
pip install python-docx openpyxl python-pptx fonttools brotli playwright img2pdf
```

Скрипты сами находят браузер в типовых местах; путь можно задать через `CHROME_BIN`.

## Структура скилла

```
skill-name/
├── SKILL.md          порядок работы, правила, что делать в спорных случаях
├── references/       методики — читаются по мере надобности
├── assets/           схемы данных, шаблоны, заполненные примеры
└── scripts/          сборка результата: PDF, DOCX, HTML
```

Вся вёрстка вынесена в скрипты: скилл заполняет JSON по схеме, скрипт превращает его в документ. Поэтому результат выглядит одинаково от прогона к прогону, а модель тратит силы на содержание, а не на CSS.
